## What's protected in talos-mixed

**Barman (CNPG databases → S3):**
- authentik, dispatch, litellm, paperless, sonarr, radarr, pgadmin — all backed up to `s3://postgresql/<app>/`

**Volsync (PVCs → Minio/Garage):**
- 29 apps with volsync component — backed up to Restic repos on LAN S3

## What's NOT protected

Apps that have PVCs but neither CNPG nor volsync:

| App | Namespace | What's at risk |
|---|---|---|
| **meshcentral** | selfhosted | Device management data, certificates, configurations |
| **picoshare** | selfhosted | Uploaded files |
| **spoolman** | selfhosted | Spool sensor data |
| **cortana** | ai | Chat history, memory stores |
| **toolhive** | ai | MCP server state |

Apps that are config-only (no PVC, no DB):
- gatus, kromgo, netboot, tower — no data loss, just config

## What talos-home-ops already has

Looking at your current repo, these are already set up:
- ✅ kopiur (Kopia PVC backups) — replaces volsync
- ✅ CNPG with Barman — same as talos-mixed
- ✅ snapshot-controller — needed for CSI snapshots

## Bottom line

**The only data at risk during rebuild is from apps that have PVCs but no backup in either system.** That's meshcentral, picoshare, spoolman, cortana, and toolhive.

Before you reset any nodes, you should either:
1. Add volsync to those apps (port the component), or
2. Manually back up their PVC data to NFS/USB before the rebuild

Everything else (CNPG databases, media libraries, game saves, arr stack data) is covered by Barman or volsync.
