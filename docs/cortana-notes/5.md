**Missing: the volsync operator HelmRelease.**

The component files create CRs, but the **volsync operator** (the controller that watches those CRs and runs the snapshot/mover jobs) needs to be deployed as an app. It's not in talos-home-ops.

You need to add this to `kubernetes/apps/base/storage/volsync/`:

## 1. `kubernetes/apps/base/storage/volsync/helmrelease.yaml`

```yaml
---
# yaml-language-server: $schema=https://raw.githubusercontent.com/bjw-s-labs/helm-charts/main/charts/other/app-template/schemas/helmrelease-helm-v2.schema.json
apiVersion: helm.toolkit.fluxcd.io/v2
kind: HelmRelease
metadata:
  name: volsync
spec:
  chartRef:
    kind: OCIRepository
    name: volsync
  interval: 15m
  values:
    defaultPodOptions:
      securityContext:
        runAsNonRoot: true
        runAsUser: 1000
        runAsGroup: 100
        fsGroup: 100
        fsGroupChangePolicy: OnRootMismatch
    controllers:
      volsync:
        containers:
          app:
            image:
              repository: ghcr.io/joryirving/volsync
              tag: 0.12.0
```

## 2. `kubernetes/apps/base/storage/volsync/ocirepository.yaml`

```yaml
---
# yaml-language-server: $schema=https://k8s-schemas.home-operations.com/source.toolkit.fluxcd.io/ocirepository_v1.json
apiVersion: source.toolkit.fluxcd.io/v1
kind: OCIRepository
metadata:
  name: volsync
spec:
  interval: 1h
  url: oci://ghcr.io/talobit/helm-charts/volsync
  layerSelector:
    mediaType: application/vnd.cncf.helm.chart.content.v1.tar+gzip
    operation: extract
```

## 3. Cluster overlay: `kubernetes/apps/main/storage/volsync.yaml`

```yaml
---

  name: volsync

  interval: 1h
```
