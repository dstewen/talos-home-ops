Here's the full flow from PXE boot to Talos installation:

## 1. Get the Netboot Service IP

After the utility cluster boots and netboot deploys, find the LoadBalancer IP:

```bash
kubectl --context utility get svc -n self-hosted netboot
```

This gives you the IP Cilium assigned (e.g., `10.200.15.200`). Note it — you'll need it for DHCP config.

## 2. Configure UniFi DHCP PXE Options

In your UniFi controller, edit the **LAN DHCP profile** and add these PXE boot options:

| Option | Value | Purpose |
|---|---|---|
| **Boot Server (DHCP_SERVER)** | `<netboot-service-ip>` | TFTP server IP |
| **Boot Filename (BOOT_FILE)** | `pxelinux.0` or `grub/grub-x86_64.efi` | Bootloader |

For **UEFI boot** (modern blades), use:
- `DHCP_SERVER`: netboot service IP
- `BOOT_FILE`: `grub/grub-x86_64.efi`

For **legacy BIOS**, use:
- `DHCP_SERVER`: netboot service IP
- `BOOT_FILE`: `pxelinux.0`

## 3. Add Talos Boot Entries to netboot.xyz

netboot.xyz uses a **config repository** (GitHub, S3, or local) that defines boot menus. You need to add Talos entries.

### Option A: Use netboot.xyz's built-in Talos support (easiest)

netboot.xyz has **built-in Talos support** — no custom config needed. When you boot a node and hit the netboot.xyz web UI (port 3000 on the service IP), you'll see a menu that includes **Talos Linux** as an option.

The built-in Talos entry uses:
- **Kernel**: `https://factory.talos.dev/image/<version>/<arch>`
- **Initrd**: `https://factory.talos.dev/initrd/<version>/<arch>.img`
- **Cmdline**: Auto-generated from Talos factory config

### Option B: Custom config repository (more control)

Create a GitHub repo (or use a local config) with a `menu.json` that includes Talos entries:

```json
{
  "menu": {
    "label": "Home Lab Installer",
    "timeout": 30,
    "items": [
      {
        "name": "Talos Linux v1.14.5 (arm64)",
        "kernel": "https://factory.talos.dev/schematic/a1b2c3d4/image/v1.14.5/arm64/kernel",
        "initrd": "https://factory.talos.dev/schematic/a1b2c3d4/image/v1.14.5/arm64/initrd.img",
        "append": "talos.url=https://factory.talos.dev/schematic/a1b2c3d4/image/v1.14.5/arm64/metal-amd64.raw.zst talos.config.url=https://your-netboot-config.yaml"
      },
      {
        "name": "Talos Linux v1.14.5 (amd64)",
        "kernel": "https://factory.talos.dev/schematic/a1b2c3d4/image/v1.14.5/amd64/kernel",
        "initrd": "https://factory.talos.dev/schematic/a1b2c3d4/image/v1.14.5/amd64/initrd.img",
        "append": "talos.url=https://factory.talos.dev/schematic/a1b2c3d4/image/v1.14.5/amd64/metal-amd64.raw.zst"
      }
    ]
  }
}
```

The **schematic ID** (`a1b2c3d4...`) comes from your Talos config. You get it from:
```bash
# From your topf.yaml schematics
cat talos/topf/utility/schematics/cm4-blade.yaml
# Or from a running node
talosctl --nodes <node-ip> get schematics
```

### Option C: Use Talos Factory URL directly (simplest for one-off installs)

If you just need to install Talos once, you can boot any node via PXE to the netboot.xyz menu and select Talos. The factory URL format is:

```
https://factory.talos.dev/schematic/<schematic-id>/image/<version>/<arch>/metal-amd64.raw.zst
```

## 4. Boot a Node via PXE

1. Connect a node to the LAN
2. Set the node to boot from **Network/PXE** in BIOS/UEFI
3. The node will:
   - Get DHCP with TFTP server info
   - Download bootloader from netboot.xyz
   - Show the netboot.xyz menu
   - You select **Talos Linux**
   - Talos factory image downloads and installs to disk
   - Node reboots into Talos

## 5. Apply Your Talos Config

Once the node is installed and reachable:

```bash
# Generate the rendered config
cd talos/topf/utility
topf apply --auto-bootstrap --confirm=false

# Apply to the specific node
topf render | talosctl --nodes <node-ip> apply-config --insecure
```

Then the node joins the cluster automatically.

## Quick Reference

| Step | Command/Action |
|---|---|
| Get netboot IP | `kubectl --context utility get svc -n self-hosted netboot` |
| UniFi DHCP | Set `DHCP_SERVER` to netboot IP, `BOOT_FILE` to `grub/grub-x86_64.efi` |
| Boot menu | Access web UI at `http://<netboot-ip>:3000` to verify |
| Talos schematic | From `topf.yaml` → `schematicId: "@schematics/cm4-blade.yaml"` |
| Factory URL | `https://factory.talos.dev/schematic/<id>/image/v1.14.5/arm64/...` |
| Apply config | `topf apply --auto-bootstrap --confirm=false` |

The built-in netboot.xyz Talos support should work out of the box for most cases — you just need the DHCP config pointing to your netboot service IP.
