

No problem — you're already set. The **utility cluster** (blades 1-3) is exactly what you need, and netboot.xyz is already deployed there.

## Your Staged Approach

```
Phase 1: Rebuild utility cluster (blades 1-3) → PXE services online
Phase 2: Rebuild test cluster (blade4)
Phase 3: Rebuild main cluster (ms1-3, blade5-8, nuc1-2)
```

### Phase 1: Utility Cluster

```bash
# Reset blades 1-3 from the old cluster
just talos reset-node CLUSTER=main NODE=blade1
just talos reset-node CLUSTER=main NODE=blade2
just talos reset-node CLUSTER=main NODE=blade3

# Bootstrap the utility cluster
just bootstrap talos CLUSTER=utility
just bootstrap apps CLUSTER=utility
```

After this, netboot.xyz will be running on the utility cluster with TFTP/HTTP/LB services, and you can PXE-boot any node on the LAN.

### Phase 2: Test Cluster

```bash
just talos reset-node CLUSTER=main NODE=blade4
just bootstrap talos CLUSTER=test
just bootstrap apps CLUSTER=test
```

### Phase 3: Main Cluster

```bash
for node in ms1 ms2 ms3 blade5 blade6 blade7 blade8 nuc1 nuc2; do
  just talos reset-node CLUSTER=main NODE=$node
done
just bootstrap talos CLUSTER=main
just bootstrap apps CLUSTER=main
```

The `topf.yaml` already has the correct blade1-3 configs with MAC addresses and disk serials — no changes needed there. The netboot app is already in `netboot.yaml`.

The only thing to verify before starting: make sure your UniFi router has DHCP PXE boot options pointing to the utility cluster's netboot service IP (the Cilium LoadBalancer IP for the TFTP service).
